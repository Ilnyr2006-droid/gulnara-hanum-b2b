# Чек-лист SEO/GEO перед выпуском

Статус: ожидает домен и завершение правовой/почтовой настройки. Сначала выполнены только пункты, которые не требуют окончательного домена.

## Уже сделано

- [x] Есть русскоязычные title, description, Open Graph title/description и семантический контент каталога.
- [x] JSON-LD проходит разбор в браузере: `Organization`, `WebPage`, `ItemList` с тремя товарами.
- [x] Для фотографий заполнены описательные alt; декоративный логотип подвала оставлен с `alt=""`.
- [x] Пороги и размеры `sizes` hero-фото и фото материала согласованы с CSS; `currentSrc` проверен в Chromium на IP-preview при 641, 700 и 760 px, DPR 1 и 2.
- [x] `sitemap.xml.template` содержит только главную страницу и явно помечен как шаблон.
- [x] IP-preview отдаёт `X-Robots-Tag: noindex, nofollow`; конфигурация HTTPS production-хоста не должна наследовать этот заголовок.
- [x] Лабораторный Lighthouse-замер стенда записан в [SEO_AUDIT_REPORT.md](SEO_AUDIT_REPORT.md).

## После выбора канонического домена

- [ ] Выбрать один HTTPS-хост (с `www` или без), настроить DNS и действующий TLS-сертификат.
- [ ] Настроить постоянные редиректы альтернативного хоста и HTTP на канонический HTTPS URL.
- [ ] На главной задать абсолютный self-referencing `rel="canonical"`, `og:url`, доступный абсолютный `og:image` и, при необходимости, абсолютные URL/ID в JSON-LD.
- [ ] Скопировать шаблон в `sitemap.xml`, заменить `https://your-domain.example/` на канонический адрес. Оставить в sitemap только доступные канонические индексируемые страницы.
- [ ] Добавить в `robots.txt` абсолютную строку `Sitemap: https://<канонический-домен>/sitemap.xml`.
- [ ] Проверить снаружи, что главная, `robots.txt`, `sitemap.xml` и файл `og:image` отвечают ожидаемыми кодами и типами содержимого; проверить XML и отсутствие тестового домена/IP в метаданных.
- [ ] Проверить после выпуска, что IP-стенд по-прежнему исключён из индекса, а индексируется только канонический HTTPS-хост.
- [ ] Проверить JSON-LD через [Google Rich Results Test](https://search.google.com/test/rich-results) и валидатор Schema.org. Сохранить ошибки/предупреждения; не добавлять цены, рейтинги или наличие без подтверждённых данных.
- [ ] Добавить сайт в Google Search Console и Яндекс Вебмастер; подтвердить права, отправить sitemap, выполнить проверку URL и исправить отчёты сканирования.
- [ ] Проверить социальное превью с доменным `og:image` и повторно проверить метаданные на опубликованном HTML.
- [ ] Повторить мобильный и desktop Lighthouse/PageSpeed на публичном HTTPS URL; сохранить настройки запуска, дату и отчёт. После накопления трафика сверить полевые Core Web Vitals.
- [ ] Проверить заголовки кеширования и выбрать стратегию для файлов изображений с неизменяемыми именами: версионированные имена/хеши и длительный кеш либо более короткий срок кеширования.

## До включения сбора заявок

- [ ] Указать фактического оператора персональных данных и его подтверждённые реквизиты/контакты; согласовать текст политики и согласия с ответственным специалистом.
- [ ] Подтвердить цель, состав, сроки и фактическую инфраструктуру обработки данных; проверить передачу данных через Resend и применимые требования к месту хранения.
- [ ] Настроить и проверить в Resend домен отправителя и DNS-записи SPF/DKIM; хранить API-ключ только в секретах среды выполнения.
- [ ] Отдельно подтвердить доставку тестового письма владельцем и проверить пользовательский путь до включения формы. Сейчас API намеренно отвечает 503, а фактическая доставка в README указана как непроверенная.

## Выпуск и контроль после публикации

- [ ] Проверить редиректы, canonical, robots, sitemap, JSON-LD, метаданные и загрузку изображений с внешней сети.
- [ ] В браузере проверить `currentSrc` для hero и материала при ширинах около 640/641/760/761 px, DPR 1 и 2; убедиться, что все изображения загружаются и alt остаются осмысленными.
- [ ] Проверить мобильное меню, контактные ссылки, форму и ошибки в консоли без отправки реальных клиентских данных.
- [ ] После индексации проверить sitemap/URL Inspection и отчёты индексирования; занести дату следующей проверки.
