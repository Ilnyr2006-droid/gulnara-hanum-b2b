# SEO/GEO-аудит

Проверка проведена 25 октября 2026 года на стенде `http://222.167.248.51:8095/` (доступ через SSH-туннель).
Lighthouse-замер снят на версии до исправления `sizes` (коммит `db344ac`). Проверка `currentSrc` после исправления выполнена на IP-preview через SSH-туннель.

## Итог

Базовая SEO-разметка и контент на русском языке присутствуют. Мобильный Lighthouse-замер стенда показал высокие лабораторные показатели. Публичный SEO-запуск пока не завершён: нет выбранного HTTPS-домена, canonical URL и рабочей карты сайта; политика персональных данных остаётся черновиком, а отправка заявок через Resend отключена.

## Проверка `sizes` и `currentSrc`

До исправления на ширинах 641–760 px CSS показывал hero-фотографию на всю ширину, тогда как `sizes` указывал `50vw`. Изображение материала занимало ширину контейнера (`100vw - 48px`), но браузеру сообщалось `45vw`. Например, при 700 px CSS-ширина hero составляла 700 px при слоте 350 px, а ширина материала — 652 px при слоте около 315 px.

В `index.html` порог hero выровнен с CSS на 760 px. Для материала `sizes` теперь отражает ширины контейнера и пропорции колонок вплоть до 1600 px. После изменения проверены фактические размеры блоков и `currentSrc`:

| Viewport | DPR | Hero: CSS slot → выбранный файл | Материал: CSS slot → выбранный файл |
| --- | ---: | --- | --- |
| 641 px | 1 | 641 px → `hero-merino-set-768.webp` | 593 px → `knit-back-detail-768.webp` |
| 700 px | 1 | 700 px → `hero-merino-set-768.webp` | 652 px → `knit-back-detail-768.webp` |
| 760 px | 1 | 760 px → `hero-merino-set-768.webp` | 712 px → `knit-back-detail-768.webp` |
| 641–760 px | 2 | выбран исходный вариант 1024 px | выбран исходный вариант 1024 px |
| 761 px | 1 | 380.5 px → `hero-merino-set-512.webp` | 320.6 px → `knit-back-detail-512.webp` |

## Источники и границы проверки

- Google Search Central: [разметка для Product snippets](https://developers.google.com/search/docs/appearance/structured-data/product-snippet) — расширенные товарные результаты ориентированы на страницы конкретного товара; наличие JSON-LD само по себе не гарантирует показ.
- Google Search Central: [создание sitemap](https://developers.google.com/search/docs/crawling-indexing/sitemaps/build-sitemap) и [изображения в поиске](https://developers.google.com/search/docs/appearance/google-images).
- Внешняя проверка в Rich Results Test, Google Search Console, Яндекс Вебмастере и PageSpeed Insights не выполнялась. Доступа к поисковой аналитике нет.
- Проверка браузером подтверждает загрузку и структуру страницы в лабораторной среде, но не подтверждает индексацию, позиции, коммерческую конверсию или полевую скорость.
